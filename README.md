🍽️ RecipeHub – Discover, Cook & Enjoy

RecipeHub by Puniket is a modern recipe discovery website designed to make cooking easier and more enjoyable. Explore recipes, discover new dishes, and find inspiration for your next meal.

✨ Features

- 🔐 User Authentication – Sign up and log in using Email & Password.
- 🌐 Google Login – Sign in with your Google account.
- 🔑 Forgot Password – Reset your password through email.
- 🍕 500+ Recipes Goal – A growing collection of delicious recipes.
- 🔍 Recipe Search – Find recipes easily.
- 🥗 Recipe Categories – Explore different food categories.
- ❤️ Favourites – Keep track of your favourite recipes.
- 👤 User Profile – View your account information.
- 📱 Responsive Design – Designed for desktop and mobile devices.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Firebase Authentication
- Google Authentication
- Firebase Hosting (planned)

🚀 Getting Started

1. Clone this repository:
   
   git clone YOUR_REPOSITORY_URL

2. Open the project folder in VS Code.

3. Configure your Firebase project in "js/firebase.js".

4. Start the website using VS Code Live Server.

🔥 Firebase Setup

RecipeHub uses Firebase Authentication for:

- Email and Password Authentication
- Google Sign-In
- Password Reset

To use authentication, configure your own Firebase project and add your website domain to Firebase Authorized Domains.
